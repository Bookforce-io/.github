# Bookforce-io/.github

Repositorio especial de la organización. GitHub lo usa para:

| Ruta | Efecto |
| --- | --- |
| `profile/README.md` | Portada pública de [github.com/Bookforce-io](https://github.com/Bookforce-io). |
| `ISSUE_TEMPLATE/` | Plantillas de issues por defecto (Bug, Mejora, Propuesta, Tarea) para todo repo sin las suyas. |
| `pull_request_template.md` | Plantilla de PR por defecto. |
| `CONTRIBUTING.md` | Guía de contribución enlazada en cada repo. |
| `workflow-templates/` | Flujos que cualquier repo instala desde **Actions → New workflow**: `cerrar-issues-produccion` y `autoria-bookforce`. |

Las pautas completas viven en el repositorio paraguas `bookforce-workspace` (`pautas/`).

> Las plantillas por defecto solo aplican a repositorios que **no** tengan su propia carpeta
> `.github/ISSUE_TEMPLATE`. Si un repo define las suyas, deben respetar las mismas secciones.
